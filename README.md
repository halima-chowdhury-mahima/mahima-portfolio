# Mahima Chowdhury — Full Stack Developer Portfolio

A modern, responsive developer portfolio built with **Next.js, TypeScript, Tailwind CSS v4, and Lucide Icons**. Featuring a premium navy-and-gold visual identity, project showcases, professional background, technical skills, and contact information.

## ✨ Features

- **Premium Design:** Elegant navy-and-gold theme with a polished, professional layout.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Navigation:** Responsive navigation with a mobile menu.
- **Hero Section:** Professional introduction, social links, and resume download.
- **About Me:** Overview of professional interests and background.
- **Technical Skills:** Organized presentation of development technologies.
- **Education & Experience:** Dedicated sections for academic and professional history.
- **Project Showcase:** Individual project detail pages with descriptions, technology stacks, challenges, future plans, and relevant links.
- **Contact Section:** Contact information and social profiles.
- **Custom Project Artwork:** Original SVG project cover illustrations.
- **SEO Ready:** Page metadata and accessibility-conscious design.
- **Reduced-Motion Support:** Respects users' reduced-motion preferences.

## 🛠️ Tech Stack

- **Framework:** Next.js App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js 20.9 or later (LTS recommended)
- npm
- Git

### Installation

1. Download or clone the repository.
2. Open the project directory in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

Verify that the project builds successfully before deployment:

```bash
npm run build
```
